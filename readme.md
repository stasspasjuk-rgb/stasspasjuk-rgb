### ⚡ QuickProducts

**QuickProducts** — моя собственная экосистема программ и утилит для Windows.

Цель проекта — создавать быстрые, удобные и красивые приложения, которые упрощают повседневную работу за компьютером.

#### 📥 QuickDownloader

Современное приложение для скачивания видео и аудио из интернета.

- ⚡ Быстрая загрузка контента
- 🎬 Поддержка различных форматов
- 🎨 Минималистичный интерфейс
- 🔧 Использование yt-dlp и FFmpeg
- 🖥️ Интеграция с Windows

#### 🔎 QuickLight

Удобная система быстрого поиска для Windows, вдохновлённая Spotlight из macOS.

- 🔍 Быстрый поиск файлов и приложений
- ⚡ Удобный доступ к нужным инструментам
- 🎨 Современный минималистичный дизайн
- 🖥️ Интеграция с Windows
- ✨ Плавные анимации и удобный интерфейс

**QuickProducts — Simple. Fast. Beautiful.**
